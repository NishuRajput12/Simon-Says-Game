🧠 Simon Says Game
A memory-based Simon Says game built using HTML, CSS, and JavaScript. Players must repeat the pattern shown by the game in the correct sequence. Each round adds a new color to the pattern, increasing the difficulty.

🛠️ Technologies Used
HTML5

CSS3

JavaScript 

🟦 Buttons
Pink (1)

Orange (2)

Blue (3)

Sky Blue (4)

Each button has a unique color and number label to help identify the correct sequence.

🎮 How to Play
Press any key to start the game.

The game will show a sequence of colors (one at a time).

Click the colored buttons in the same order.

With each round, the sequence gets longer.

The game ends if you click the wrong color.
